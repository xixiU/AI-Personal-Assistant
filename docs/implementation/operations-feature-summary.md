## 🎯 核心功能

### 1. 权限控制
- **白名单机制**: 支持飞书、Web、微信多渠道用户身份
- **审批流程**: 危险操作需管理员审批（多人、一人同意即可、超时自动取消）
- **操作审计**: 所有操作混入 chat_history，完整记录操作链路

### 2. 机器和应用管理
- **自然语言描述**: AI 可理解"生产1号""订单服务"等别名
- **灵活配置**: 支持同机器多版本、自定义脚本路径
- **智能查找**: 模糊匹配机器名/别名/描述
- **SSH 连接**: 支持密钥和密码两种认证方式

### 3. 运维指令系统
**9个内置指令**（可扩展）:
- `get_app_status` - 查询应用运行状态（低风险）
- `get_app_version` - 查询版本/分支（支持 jar/log/file/api 多源）
- `get_jar_info` - 分析 jar 包（manifest/pom/git.properties）
- `get_process_info` - 进程详情（端口/线程/内存/连接）
- `get_system_metrics` - 系统资源（CPU/内存/磁盘/网络）
- `get_logs` - 查看日志（tail + grep）
- `restart_app` - 重启应用（高风险，需审批）
- `stop_app` - 停止应用（高风险，需审批）
- `start_app` - 启动应用（中风险，需审批）

**扩展性**:
- 继承 `OperationCommand` 基类
- 通过 `CommandRegistry.register()` 注册
- AI 自动识别新指令

### 4. 审批机制（飞书）
- **审批卡片**: 红色警示、风险等级图标、命令预览、倒计时
- **多人审批**: 循环发送给所有审批人，一人同意即可
- **超时控制**: 默认 180 秒，可配置
- **状态流转**: pending → approved/rejected/timeout

### 5. AI 集成
- **触发方式**: `/运维` 或 `/ops` 关键词
- **会话粘性**: 进入运维模式后，追问自动继承（不受上下文窗口影响）
- **Agentic 循环**: Claude 自主决策工具调用顺序
- **工具自动注册**: 反射 OperationsTools 方法生成 schema
- **审批提示**: 危险操作自动告知用户"已向管理员发送审批请求"

## 🏗️ 架构设计

### 分层架构

```
┌─────────────────────────────────────────────┐
│  用户层（飞书/Web/微信）                      │
│  /运维 查看生产1号的订单服务状态               │
└─────────────────────────────────────────────┘
              ↓
┌─────────────────────────────────────────────┐
│  AI 层（AnthropicProvider）                  │
│  - 触发检测（/运维 关键词）                   │
│  - 鉴权（is_authorized）                     │
│  - Agentic 循环（多轮工具调用）               │
│  - 会话粘性（_operations_sessions）          │
└─────────────────────────────────────────────┘
              ↓
┌─────────────────────────────────────────────┐
│  工具层（OperationsTools）                   │
│  - 封装指令调用                               │
│  - 统一返回格式                               │
│  - 审批流程集成                               │
└─────────────────────────────────────────────┘
              ↓
┌─────────────────────────────────────────────┐
│  指令层（OperationCommand）                  │
│  - 内置指令（9个）                            │
│  - 自定义指令（用户扩展）                     │
│  - 风险评估                                   │
└─────────────────────────────────────────────┘
              ↓
┌─────────────────────────────────────────────┐
│  执行层（OperationsManager）                 │
│  - SSH 连接池                                │
│  - 命令执行（安全拼接）                       │
│  - 审批队列管理                               │
│  - 密码加密                                   │
└─────────────────────────────────────────────┘
              ↓
┌─────────────────────────────────────────────┐
│  审批层（ApprovalProvider 抽象）             │
│  - FeishuApprovalProvider（飞书实现）        │
│  - WebApprovalProvider（待扩展）             │
└─────────────────────────────────────────────┘
```

### 解耦设计

1. **审批层抽象**: `ApprovalProvider` 接口，支持多渠道扩展
2. **指令系统**: `OperationCommand` 基类 + `CommandRegistry` 注册中心
3. **工具封装**: `OperationsTools` 统一接口，AI 无需关心底层细节
4. **身份抽象**: `OperatorIdentity` 渠道无关的用户身份
